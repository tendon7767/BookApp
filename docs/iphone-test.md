# iPhone 15 / iOS 26.6.1 實測

此清單尚待真機完成；Playwright WebKit 通過不表示以下全部已通過。

本機 Windows WebKit 的 Playwright `setOffline(true)` 後重載回報內部錯誤。完整斷網模擬保留在 Chromium；WebKit 改以停止來源伺服器後重開，驗證 HTML／JS／CSS 從快取載入與設定保留。這只涵蓋來源無法連線，不等同真機飛航模式。

## 前置

1. 發布正式 build 至 GitHub Pages（見 README），以 HTTPS 開啟 /BookApp/。
2. 初次連線後等待「可離線開啟」。
3. Safari 選單 → 分享 → 加入主畫面；如出現「以網頁 App 打開」請開啟。
4. 從主畫面圖示開啟，再次等待離線準備完成。Safari 分頁與主畫面 App 不假設共享全部狀態。

- [ ] 從 v1 升級後原有主題設定不遺失。

- [ ] 點 EPUB 封面先開書籍資訊，按「開始閱讀」開書，左右點按與左右滑動可逐頁閱讀。

- [ ] 返回書架、關閉 App、再次開書回到同一內容位置。
- [ ] 鎖屏、切換 App、Safari 工具列伸縮與直橫旋轉後位置保持在同一段附近。
- [ ] 飛航模式下第一次開啟已匯入 EPUB，也能翻頁、開目錄、看插圖與保存位置。
- [ ] 短時間反覆進出大型 EPUB，沒有殘留閱讀畫面或凍結。
- [ ] 暖紙／明亮／深夜外觀均能閱讀；捏合縮放未被禁止。

## Milestone 4 排版驗收

- [ ] 點 Aa 後可快速修改字級，仍看得到上方書籍內容。
- [ ] 宋體／黑體／等寬在本機顯示，字級、行距、段距和左右邊距立即反映。
- [ ] 連續調整大小、間距、主題後，原本那一段仍出現在當頁；翻頁後從新位置繼續。
- [ ] 主題與自訂文字／背景色生效，書內指定顏色不會讓深夜模式的正文消失。
- [ ] 直向／橫向、較小螢幕均可捲動面板並關閉，系統選色器可正常返回。
- [ ] 離線改設定、關閉再開書，位置與本書設定仍在；其他書與書架設定不被改動。
- [ ] 重設排版回復預設值且不跳回書首。

## Milestone 5 TXT 驗收

- [ ] 原本匯入的 TXT 可直接開啟，不需要重新加入。
- [ ] UTF-8、UTF-16、Big5／GBK 的常用書檔可閱讀；遇到亂碼可切換編碼，重開仍記住選擇。
- [ ] 第一章／第12回／Chapter 1 等標題出現在目錄，跳章正確。
- [ ] 點按、滑動、快速進度、首頁與末頁行為正常；連續前後翻頁沒有漏字。
- [ ] Aa 字級、字體、行距、段距、邊距、顏色即時生效，仍留在同一文字位置。
- [ ] 重開、直橫旋轉、鎖屏再開，仍可從上次位置閱讀。
- [ ] 約 8 MB 長篇開書與翻頁手感可接受，沒有一次出現整本內文或頁面凍結。
- [ ] 飛航模式下首次開啟已存的 TXT，仍能看目錄、排版、翻頁及保存位置。

## Milestone 6 書庫管理驗收

- [ ] 搜尋書名／原書名／作者／分類，沒有結果時可一鍵清除篩選。
- [ ] 修改書名、作者、分類後，封面文字與書架立即更新；重開仍保留。
- [ ] 改名後原檔與閱讀位置、排版不變，再次匯入同檔不產生重複書籍，也不覆蓋新書名。
- [ ] 分類可新增或選用既有項目，清空分類後出現在未分類；分類清空或刪光時篩選狀態仍可操作。
- [ ] 閱讀到中間返回書架，顯示正確百分比並排在最近閱讀最前面；重開不誤標為已讀完。
- [ ] 進出閱讀器後保留搜尋／篩選，切換書名排序和最近加入結果合理。
- [ ] 飛航模式下改名與分類、重開 App 後仍保留；鍵盤開啟時可捲到儲存／取消按鈕。
- [ ] 書庫捲動時搜尋／分類／排序固定上方，書籍總數與加入書籍／批次編輯整合在底部工具列；末本書能完整捲到操作列上方。
- [ ] 安全區與 Safari 工具列伸縮時，上下固定列不遮住點按目標；搜尋鍵盤收起後畫面恢復正常。
- [ ] 書卡百分比置於封面下緣的進度條內，深淺封面都可辨識；書架不顯示作者、格式或 info 圖示，書名最多三行。
- [ ] 選取多本、全選目前結果、取消全選、批次分類（含清空）均正常；切換搜尋後仍能從確認清單辨識所有選取書籍。
- [ ] 批次移除前顯示正確本數／書名，可以取消；確認後只刪除選定書籍的本機資料。
