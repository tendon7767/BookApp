# 產品決策

- App 名稱：看書；繁體中文；個人與少數親友使用，無廣告。
- 介面只保留實際操作與狀態；不用氣氛標語、宣傳區塊或大字標題佔用手機空間。
- 主要實機：iPhone 15 / iOS 26.6.1（使用者提供；仍需實測）。
- React + TypeScript + Vite，純前端 PWA，初期不使用 Apps Script 或其他後端。
- GitHub repository：tendon7767/BookApp；網站路徑固定 /BookApp/。
- EPUB / TXT 優先，PDF 與其他格式待實際檔案確認後排程。
- 最終支援分頁／捲動、橫排／直排與快速排版調整，分階段驗收。
- Google Drive 是雲端主書庫；IndexedDB 保存下載檔案與尚未同步的變更。
- 用 Google Picker 明確選書加入，使用 drive.file。並不自動掃描任意資料夾的新檔案。
- 書架索引和完整書檔分開，點開書才下載；可手動保留離線。
- 雲端原檔不為了加入書架而複製。App 改名／分類先存於自己的 metadata。
- 書架移除、移除手機下載、刪除雲端原檔是不同操作。
- 同步需保留衝突與尚未上傳的變更，不用整份 JSON 無條件覆寫。
- Drive OAuth 可能需要重新連接，離線閱讀不依賴登入。
- 已提供 Drive 測試資料夾；其 ID 不寫入 App，未來每個使用者使用自己的帳號與選取檔案。

## Milestone 1 範圍

本次只交付 App shell、安裝說明、responsive / safe-area、外觀偏好持久化、Service Worker 快取、更新提示、CI 與 Pages 發布流程。無匯入／讀書／Google OAuth，介面明確標示尚未提供的功能。

資料庫 v1 只建立已實際使用的 preferences store。Book / Progress / ReaderAdapter 先定義內容位置與格式邊界；書檔及同步 stores 等實作時再以 migration 新增。

## Milestone 2 範圍

- 新增 EPUB / TXT 多檔匯入與本機保存；Drive 測試資料夾目前以 TXT 為主，因此提前加入 TXT 原檔匯入。
- 只保存 TXT 原始位元組；文字解碼、章節與閱讀位置待文字閱讀器實作。
- IndexedDB 升為 v2，新增 books / bookFiles / bookCovers，保留 v1 preferences。
- 書目／原檔／封面在同一交易保存或移除；內容雜湊去重，併發匯入也只存一份。
- 封面接近可見區才載入，離開元件時撤銷 Object URL。
- 由於 Windows WebKit 寫入 Blob/File 失敗，二進位改存 ArrayBuffer + MIME，讀取時還原 Blob。原始內容不變，保留讀取早期 Blob 記錄的能力；不能據此宣稱 iPhone 有相同缺陷。
- 單本 50 MB 上限，逐本處理；EPUB 套件資訊和封面讀取設解壓大小上限。
- 匯入期間不套用 App 更新，避免中斷批次。已完成項目逐本保存，單本失敗不影響其他檔案。
- 未實作閱讀器、雲端備份、完整書庫編輯與搜尋。

## Milestone 3 範圍

- EPUB 閱讀器與 UI／IndexedDB 分離；EPUB 2/3 可重排內容先行，TXT/PDF 保留各自模組邊界。
- IndexedDB v3 新增 progress 與可丟棄的 epubLocations；刪書同時清除兩者，舊版書目、原檔、封面與設定保留。
- 逐次 relocated 保存 CFI，按回書架前等待寫入；visibilitychange/pagehide 再嘗試保存。保存失敗有提示，不宣稱成功。
- 每章計算進度位置並讓出執行時間；完整索引與原檔 hash 關聯保存，下次不用重算。索引故障不阻擋逐頁閱讀。
- 百分比以當頁第一段內容計算，所以滑至 68% 後可能顯示約 66–68%；重新開啟仍用 CFI 而非百分比。
- WebKit sandbox 內事件未正常觸發，改由父頁手勢層負責點按和滑動；不開啟書內腳本。此模式尚不支援書內連結、選取、註記。
- 本次以使用者授權的兩本 Drive EPUB，在 Chromium／WebKit 驗證；只保存忽略目錄中的本機副本，不更動 Drive、不提交書檔。
- 閱讀排版面板、TXT 閱讀、Drive 同步仍是後續 milestone。

## Milestone 4 範圍

- 共用 ReadingSettings 模型與獨立 Aa 面板，不將排版 UI 綁在 EPUB API；TXT 後續可以使用同一設定。
- IndexedDB v4 只新增 readerSettings，按 bookId 保存設定與 updatedAt；刪書同時刪除排版設定。
- 內建字體、字級、行距、段落間距、左右邊距、暖紙／明亮／深夜與自訂文字／背景色；無外部字型下載。
- Aa 面板顯示在底部，調整直接反映上方書籍內容；快速連續操作合併尚未開始的重排，保留最後值。
- 重排期間保留同一 CFI anchor，待 CSS、字型與欄位計算完成再定位；測試同時驗證保存 CFI 與該位置文字的實際可見範圍。
- 書內可重排文字會覆寫出版方的字級、字體、行距與文字色；圖片不套用反色濾鏡。
- 使用者已試讀上一階段，本階段仍需手機確認設定面板與手感。
- 翻頁動畫延後；下一項主要功能為 TXT 閱讀與編碼／章節辨識。

## Milestone 5 範圍

- 新增獨立 TextEngine 與 TXT 解碼 worker；ReaderView、目錄、手勢與 Aa UI 共用，EPUB 仍使用 epub.js 與 CFI。
- TXT 解碼優先 BOM／合法 UTF-8；Big5／GB18030 採啟發式評分，使用者可手動指定。支援 UTF-16 LE／BE；無法完全可靠辨識所有無 BOM 舊編碼。
- worker 同時建立自動章節目錄；只在畫面建立當頁附近的段落，不預先排整本。解碼文字仍會完整保留在記憶體，50 MB 原檔限制仍適用，不宣稱手機可處理任意大小。
- 用 grapheme 邊界切當頁，前後頁保持文字覆蓋，最近 500 頁邊界暫存；重排後可按保留的文字偏移直接開頁。原檔空白行以段距呈現，索引不刪除。
- 文字位置 v1 為 BOM 移除、CRLF／CR 轉 LF 後的 UTF-16 code-unit offset；progress 的 TXT location 增加選用 encoding、encodingChoice、textVersion 欄位，同一記錄原子保存。此為既有 v4 store 的相容欄位擴充，不需要新 store 或資料清除。
- 切換編碼以相對進度近似定位；正常翻頁、重排與重開以文字偏移還原。編碼與原始位元組不混為一談，不將解碼結果覆寫原檔。
- 真實 Drive TXT 約 8 MB、UTF-16 LE、896 章，在獨立 Chromium／WebKit context 驗證開書、翻頁、68% 跳轉、Aa 與位置保存；私人檔案與截圖僅存忽略目錄。
- 下一階段為書庫搜尋、改名、分類與最近閱讀；Drive 同步、PDF、翻頁動畫仍未實作。

## Milestone 6 範圍

- 書庫搜尋涵蓋目前／原始書名、作者、分類與原始檔名；全半形、大小寫與多關鍵字比對皆在本機處理。
- 單本一個自由文字分類，已有分類提供輸入建議；篩選含全部／未分類。最近閱讀為預設排序，另提供最近加入與書名自然數字排序。
- 封面下直接顯示進度；書籍資訊顯示最後閱讀時間，並集中書名、作者、分類的編輯操作。尚未讀過與已讀 0% 分開呈現。
- 書庫只讀 books / progress，不為了搜尋或排序載入書籍 Blob；資料庫維持 v4，沿用既有 category、modifiedAt 與 progress.updatedAt。
- 編輯只在 books store 的交易內修補可編輯欄位，不修改 originalTitle／檔案／hash／封面／CFI 或 TXT 偏移／排版；已刪除的書籍不能被晚到的編輯復活。儲存失敗保留表單，顯示錯誤並允許重試。
- 修正 WebKit 離開 TXT 時可能收到已卸載畫面的 resize 回呼：不再對離線 DOM／零尺寸畫面計算與寫入進度，避免誤標成已讀完。
- 搜尋、編輯、篩選和排序均可離線使用；後續進入 Google Drive OAuth 與同步階段，需實際設定應用程式憑證，不將測試資料夾寫死在 App。

### 書架操作調整

- 保留品牌圖示並縮矮 header，移除書架／設定的重複頁面標題。
- 搜尋／分類／排序固定於頂部，選單左側加圖示並保留文字。書籍總數與「加入書籍／批次編輯」共用一條固定底部的平整工具列，不加陰影；底部導航已移除，header 右側以圖示進入設定、返回書架。設定與閱讀時不顯示書庫操作列。
- 書卡每列三本（極窄畫面兩本），作者只在資訊頁顯示；進度條覆蓋封面下緣，百分比置中疊在進度條內。書名 14px、最多三行；封面不放檔案類型或 info 按鈕。點書先開啟資訊，再按「開始閱讀」。系列不顯示上次閱讀的集數提示；進度條高 16px 並使用半透明底色。
- 選取模式支援全選目前結果、逐本切換、批次分類／本機移除；篩選外已選書仍計入數量，確認視窗列出完整選取清單。取消或完成操作後退出選取模式。
- 批次分類／移除皆使用單一交易，錯誤整批回復。分類交易遇到已刪除的目標直接中止，避免部分套用；不寫回 Blob 或改變閱讀位置。

## 平台界線（持續適用）

- 首次使用需上網，快取完成後才可離線啟動。
- IndexedDB 和 Cache Storage 可能被清除；離線啟動不是永久保存保證。
- 沒有背景永久執行／永遠免重新授權的承諾。
- 用裝置內建字體，不從 Google Fonts / CDN 載入資源。
- 不禁止使用者縮放；包含減少動態效果、鍵盤焦點、原生 modal dialog。
- WebKit 自動測試不能代替 iPhone Safari / 主畫面安裝實測。

### 系列整理

- books 增加可選 series / volume 欄位，舊 v4 記錄的缺值視為無系列，不需升版 object store 或重寫書檔。單本修改未傳 series 時保留原值；明確清空系列同時清空集數。
- 分類與系列獨立；系列名稱去除前後空白後精確比對。集數允許正小數，未填集數排最後，同集数以書名自然排序。
- 書架先搜尋／篩選／排序再分組；系列占第一本符合書籍的位置。卡片顯示符合本數／總本數，進入後仍保留篩選。批次編輯展開書籍，全選只選目前結果。系列內固定依集數排序。
- 開啟批次系列設定時，取所選原始書名最長的連續共通文字原樣預填系列名，不去空白、符號、數字、集數標記，也不轉換全半形；每本書取第一組阿拉伯數字，沒有則取中文數字預填集數。不要求格式標記、不同集數或同系列，不排除年份，也不另查檔名。已有的使用者設定保留，建議可修改／取消，點套用才寫入。
- 批次套用使用單一交易，全部成功才更新 UI。系列編輯不改寫書名、分類、原始檔案及閱讀進度。

- 一般與批次工具列的按鈕高度 56px，下方另留安全區加 14px，上方 10px。清單保留足夠尾端空間，最後一本書可捲到工具列上方。
- 匯入完成只顯示摘要（加入／重複／失敗本數），點「查看詳情」才展開原始訊息；提示可手動關閉。

## 預設排版與介面一致性

- preferences/app 新增選用 readingDefaults 欄位，維持 v4 相容；單本設定優先於全域預設。僅實際自訂排版才保存單本設定，保留舊版已有的單本設定。
- 設定頁共用 Aa 面板提供預覽與明確儲存；失敗保留草稿可重試。
- 書籍資訊左上垃圾桶共用批次移除確認，取消返回資訊；底部改為返回書架。
- 頂部品牌列高 56px，搜尋與篩選控制同為 44px，共用頁面左右邊距；UI 統一 18px 標題、16px 區段、14px 內文、12px 輔助資訊，閱讀正文獨立。底部加入書籍與批次編輯加大間距。
- App 外觀新增工程師深灰、霧藍、鼠尾草綠；閱讀配色保持獨立。未保存閱讀預設／單本設定時，三者分別以深夜／明亮／暖紙作為閱讀初始主題。

## Milestone 7 第一段：Google 連接與按需下載

- 維持 Google Drive 主書庫方案；不改成手動匯出備份。純前端 GIS token model + Google Picker，scope 僅 drive.file；Cloud project 與資料夾不寫死。
- 加入書籍可選裝置或 Drive；Google 設定可由 Vite 環境變數提供，或先在 App 填公開設定。
- IndexedDB v5 新增 cloudPreferences / cloudBooks，保留既有書籍、位元組、進度與設定。雲端書目以帳號 permissionId + fileId 為鍵。
- 選檔僅存書目，按下載才讀取 Blob；Google Picker 提供上傳分頁。API 分頁、授權失敗、過期、下載取消、50 MB 上限、實際大小與版本確認皆有處理。
- Token 僅記憶體保存，不寫 IDB、URL 或 SW。中斷或切換帳號不清除本機書籍。雲端 SDK 僅在有設定、連線且開啟雲端頁時載入。
- 原檔不同版本不覆寫既有本機書籍，避免把舊 CFI／偏移套到不同內容；同內容依 hash 去重，保留使用者本機修改。
- 本段沒有 metadata／進度／排版上傳或衝突合併，UI 明確說明；後續同步需保留離線變更，不能無條件覆蓋。
- 測試用 SDK／API 替身；真實登入、上傳與 iPhone standalone 仍需完成 Google 設定後驗收。詳見 google-drive-setup.md。

## Milestone 7B：App 為唯一管理入口

此節取代前述 7A 的 Picker 選書／上傳流程。

- App 加書後自動備份，Picker 僅選備份資料夾。Drive 保存 App 管理的原檔與書架快照，不掃描任意書籍資料夾。
- IndexedDB v6 增加 syncState；快照與原檔分離，SHA-256 身分、持久化 outbox、固定上傳 ID、resumable chunks、Web Locks 排他操作。
- 欄位版本使用 vector clocks / multi-value registers，同時修改保留兩方並顯示選擇；不同欄位直接合併。CFI／TXT 位置是一個整體，不取最大百分比。
- 還原先恢復書架、設定與封面，原檔按需下載。分類、系列、集數、個別排版、預設排版、外觀與排序一起保存。
- 刪除同步使用 tombstone；另有「僅移除本機下載」。歷史快照與刪除原檔暫時保留，不自動清理；雲端頁顯示最近 20 份可還原版本。
- Token 僅記憶體；需再次連接才能恢復雲端操作。不承諾 iOS 關閉 App 後背景同步，也不承諾未完成上傳跨重開從中間位元組繼續。
- Google 邊界模擬測試和實際 Google / iPhone 驗收分開，不能將 mock 通過視為真實 OAuth 已驗收。
